# Senti-Pred: Modular Python Scripts

This guide details how to run the Senti-Pred project using the modular Python scripts located in the `src/scripts/` directory.

## Overview

This approach is ideal for those looking for more controlled, modular execution that can easily be integrated into other systems or automated workflows. The scripts cover everything from exploratory data analysis to model training and final evaluation.

## Script Structure

-   `src/scripts/01_eda.py`: Exploratory Data Analysis (EDA) - generates distribution charts and initial visualizations
-   `src/scripts/02_preprocessing.py`: Performs preprocessing and cleaning of the English-language data
-   `src/scripts/03_modeling.py`: Trains multiple classification models and saves the best one
-   `src/scripts/04_evaluation.py`: Evaluates the performance of the trained model with detailed metrics

## Execution Flow

The scripts must be run in sequential order, since each one depends on the artifacts generated by the previous one:

### 1. Exploratory Data Analysis (EDA)

```bash
python src/scripts/01_eda.py
```

**What it does:**
- Loads the raw data (`twitter_training.csv` and `twitter_validation.csv`)
- Generates statistical analyses and visualizations
- Saves charts in `reports/visualizacoes/`

**Generated artifacts:**
- Sentiment distribution charts per split
- Text length analysis
- Top most frequent words

### 2. Data Preprocessing

```bash
python src/scripts/02_preprocessing.py
```

**What it does:**
- Cleans and normalizes the texts (removes URLs, mentions, hashtags, numbers)
- Removes English stopwords
- Applies lemmatization with POS tagging
- Saves processed data in pickle format

**Generated artifacts:**
- `data/processed/processed_data.pkl` - contains processed DataFrames for training and validation

### 3. Model Training

```bash
python src/scripts/03_modeling.py
```

**What it does:**
- Loads processed data from the pickle
- Trains three different models: LogisticRegression, MultinomialNB and LinearSVC
- Compares performance using macro F1-score
- Saves the best model and detailed metrics

**Models tested:**
- **LogisticRegression**: Multiclass logistic regression
- **MultinomialNB**: Naive Bayes for text features
- **LinearSVC**: Linear SVM optimized for large datasets

**Generated artifacts:**
- `src/models/sentiment_model.pkl` - best model saved (joblib)
- `reports/metrics/model_metrics.json` - detailed metrics for all models
- Comparative charts (ROC, Precision-Recall, Confusion Matrices) in `reports/visualizacoes/`

### 4. Final Evaluation

```bash
python src/scripts/04_evaluation.py
```

**What it does:**
- Loads the trained model and the processed data
- Generates final evaluation metrics
- Creates additional performance visualizations

**Generated artifacts:**
- Consolidated final metrics
- Detailed confusion matrix
- Additional performance analyses

## Requirements and Dependencies

Make sure all project dependencies are installed:

```bash
pip install -r requirements.txt
```

Or install the specific dependencies of the scripts:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn nltk joblib
```

## NLTK Resource Download

The scripts download the required NLTK resources automatically, but if problems are found, run the download manually:

```python
import nltk
nltk.download('punkt')
nltk.download('stopwords')
nltk.download('wordnet')
nltk.download('omw-1.4')
nltk.download('averaged_perceptron_tagger')
```

## Expected Data Structure

The scripts expect to find the raw data in the following format:

**Files:**
- `data/raw/twitter_training.csv`
- `data/raw/twitter_validation.csv`

**CSV format:** (no header, 4 columns)
```
tweet_id,entity,sentiment,text
```

**Sentiment classes:**
- `Positive`: Positive sentiment
- `Negative`: Negative sentiment  
- `Neutral`: Neutral sentiment
- `Irrelevant`: Out of scope (optional)

## Output and Results

After running all the scripts, you will have:

### Trained model
- **Location:** `src/models/sentiment_model.pkl`
- **Type:** Complete scikit-learn pipeline (TF-IDF + Classifier)
- **Best model:** LinearSVC (based on macro F1-score)

### Performance metrics
- **Location:** `reports/metrics/model_metrics.json`
- **Includes:** Accuracy, F1-score, ROC-AUC, Precision-Recall for each model
- **Training time:** Recorded for efficiency analysis

### Visualizations
- **Location:** `reports/visualizacoes/`
- **Charts:** Distributions, confusion matrices, ROC/PR curves, text analyses

## Troubleshooting

### Error: "Processed data not found"
Run the `02_preprocessing.py` script before `03_modeling.py`

### Error: "Model not found"
Run the `03_modeling.py` script before `04_evaluation.py`

### Error: NLTK resources not found
Run the manual download of the NLTK packages as shown above

### Slow performance
- Consider reducing `max_features` in the TfidfVectorizer
- Use a smaller sample of the data for tests
- Check that you have enough RAM (recommended: 8GB+)
